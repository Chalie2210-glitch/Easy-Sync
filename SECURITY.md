# Security

Use GitHub private vulnerability reporting when available. Do not put credentials,
audio assets or private project paths in public issues.

Updates accept only stable releases from Chalie2210-glitch/Easy-Sync and require the
expected installer name, URL, size and GitHub SHA-256 digest. Checksums detect corrupt
or mismatched downloads; they do not replace signing. Initial binaries are unsigned.

WAAPI should be limited to trusted interfaces. Instance IPC binds to localhost.
